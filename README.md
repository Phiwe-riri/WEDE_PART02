# WEDE_PART02

Forever Cool Website

Project Description

Forever Cool is a clothing website created to showcase clothing products and provide customers with information about the brand. The website was developed using HTML, CSS, and JavaScript.

Live Website

https://Phiwe-riri.github.io/WEDE_PART02/Home.html

Website Features

Home page introducing Forever Cool.
About Us page explaining the brand.
Products and Services page displaying clothing items and prices.
Images page displaying website images.
News page for updates and announcements.
Contact page for customer enquiries.
Enquiry form with product selection and quantity calculation.
JavaScript features for searching and interacting with website content.
Responsive styling and SEO improvements.
Products

Vests — R299
T-Shirts — R499
Hoodies — R599
Technologies Used

HTML for website structure.
CSS for styling and layout.
JavaScript for interactivity and form functionality.
Git and GitHub for version control and hosting.
